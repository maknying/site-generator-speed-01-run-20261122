Faster drop-in for makefun-site 1.0.0: a dependency-free `solve.js` whose `run(input)` returns byte-for-byte the same output tree as makefun-site 1.0.0, about 3.4x faster than the house baseline on the practice set (CPU time of `run()`).

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`) and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).
